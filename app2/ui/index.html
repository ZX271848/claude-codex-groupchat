手机与电脑，一起群聊

Mac 和 iPhone 连接 Tailscale、登录同一账号后，在 iPhone 的 Safari 打开下方 HTTPS 地址。配对后，点击分享 → 添加到主屏幕 → 添加。

尚未开启

Mac 需要保持开机并运行群聊。仅通过 Tailscale 私有加密网络连接，普通局域网设备无法访问。配对后的设备可以操作这些群聊和项目。
